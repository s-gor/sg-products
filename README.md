## Продукты

| Продукт | Платформа | Назначение |
| :--- | :--- | :--- |
| **SG-Mobile** | Android | Универсальный VPN-клиент с несколькими сетевыми ядрами, SG-Net и Shadowsocks/Outline |
| **SG-Client** | Windows | Настольный VPN- и proxy-клиент с управлением подключениями, подписками и маршрутизацией |
| **SG-Net** | Server / Clients | Собственный сетевой протокол и серверная инфраструктура с транспортами TLS, WSS и H3/QUIC |

**SG — Security Groups** объединяет клиентские приложения, сетевые транспорты и серверные инструменты в одну экосистему. Каждый продукт может использоваться самостоятельно, а совместимые компоненты могут работать вместе.

## SG-Mobile

**Android · ARM64 · VPN / SOCKS5 · Multi-core**

SG-Mobile — Android-приложение для подключения к собственным и сторонним VPN- и proxy-серверам. Приложение объединяет разные протоколы и сетевые ядра в одном интерфейсе: импорт профилей, подписки, управление подключением, DNS, маршрутизацию и диагностику.

### SG-Mobile 084 — что нового

**Текущая описываемая сборка: 084 FIX6**  
**Версия приложения:** `0.0.110-084-FIX6` · `versionCode 212`  
**Совместимость:** Android 8.0+, `arm64-v8a`

#### 1. Shadowsocks и Outline

- Добавлена поддержка ссылок **`ss://`** и Shadowsocks-профилей.
- Поддерживаются обычные ссылки, Base64-кодирование, импорт по ссылкам и из подписок.
- Добавлен отдельный транспорт на базе **Outline SDK** для Shadowsocks-ссылок с параметром `prefix`.
- Outline-префикс сохраняется как исходная последовательность байтов, включая префиксы с двоичными значениями в URL.
- Обычный Shadowsocks использует Xray; профили, которым необходим Outline `prefix`, направляются через Outline-совместимое ядро.
- Разделены обработка профиля и выбор сетевого движка, чтобы ссылка с `prefix` не запускалась ошибочно как обычный Shadowsocks.
- Исправлены конфигурация Shadowsocks для Xray и тесты импорта подписок.

#### 2. Поддержка SG-Net

В SG-Mobile интегрированы три транспорта SG-Net:

| Транспорт | Тип соединения |
| :--- | :--- |
| **TLS** | Прямое соединение через TLS |
| **WSS** | WebSocket поверх TLS |
| **H3** | HTTP/3 поверх QUIC |

SG-Net работает вместе с остальными протоколами приложения. Поддержка H3 зависит от сетевых условий и доступности UDP на стороне сервера и клиента.

#### 3. Обновлённые сетевые ядра в FIX6

| Компонент | Версия |
| :--- | :--- |
| **Xray / libXray** | `26.10.29` |
| **sing-box** | `1.14.4` |
| **Mihomo** | `1.19.33` |
| **Mieru** | `3.39.0` |
| **Hysteria2** | `2.13.0` |
| **AmneziaWG** | AWG 3.1 |
| **Outline SDK** | `v0.0.23` |

Для sing-box сохранена используемая SG-конфигурация сборки с Naive/Cronet. Hysteria2, AmneziaWG, Outline SDK и SG-Net в FIX6 не заменялись без необходимости.

#### 4. Интерфейс и повседневная работа

В SG-Mobile доступны:

- **VPN/TUN и локальный SOCKS5**, управление запуском и остановкой подключения.
- Импорт профилей и подписок, включая QR-ссылки.
- Отдельные настройки DNS, маршрутизации, GeoIP/GeoSite и IPv4/IPv6.
- Поддержка нескольких сетевых движков в одном приложении.
- Просмотр состояния и диагностика подключений.
- Светлая и тёмные темы, включая **SG Soft** и **Pure Black OLED**.

В линии 084 основное внимание уделено расширению совместимости профилей, подключению SG-Net и Outline, обновлению ядер и сохранению существующих возможностей без переустановки приложения.

#### 5. Обновление приложения

При обновлении SG-Mobile устанавливайте новую версию **поверх существующей**. Не удаляйте приложение ради обновления: при одинаковом идентификаторе приложения и корректной подписи Android сохраняет данные установленной версии.

Для проверки подлинности используйте контрольную сумму SHA-256 опубликованного APK и сведения о выпуске. Файлы ключей и подписи в публичном репозитории не размещаются.

## SG-Client

**Windows 10/11 x64 · Portable · VPN / TUN / System Proxy / Local Proxy**

SG-Client — универсальный Windows-клиент Security Groups для собственных и сторонних VPN- и proxy-серверов. В одном интерфейсе доступны разные сетевые ядра, импорт профилей и подписок, маршрутизация, диагностика и управление подключениями.

### SG-Client 104 — сборка 0.0.104.0 · что нового

**Точная версия приложения:** `0.0.104.0` (`AssemblyVersion` / `AssemblyFileVersion`)  
**Номер выпуска:** `104`  
**Текущая редакция сборочного комплекта:** `SG104-DNS.zip` (исправление определения страны при локальной подмене DNS)  
**Платформа:** Windows x64 · Portable  
**Основное направление выпуска:** обновление ядер, полноценная интеграция SG-Net и улучшения повседневной работы.

> **О нумерации:** номер `0.0.104.0` подтверждён в `src/SG-Client/Properties/AssemblyInfo.cs` и в `ServiceLib`. Суффикс `DNS` обозначает редакцию ZIP-комплекта, **а не новую версию EXE**: отдельный номер ревизии исправлений в исполняемом файле пока не задан. Поэтому разные комплекты `104` могут иметь одну и ту же внутреннюю версию. Для следующих публичных выпусков необходимо увеличивать номер сборки в приложении и указывать его здесь.

#### 1. Обновлённые сетевые ядра

В рабочей сборке SG-Client 104 обновлены следующие компоненты:

| Компонент | Версия |
| :--- | :--- |
| **Xray-core** | `26.10.29` |
| **sing-box** | `1.14.4` |
| **Mihomo** | `1.19.33` |
| **AmneziaWG** | `3.1.0` · инструменты `3.1.20260812` |
| **SG-Net** | Собственное ядро, поддержка TLS / WSS / H3 / Auto |

Сохранена работа с другими поддерживаемыми клиентом движками и форматами профилей. Обновление отдельных ядер не требует изменения SG-Net, пользовательских ключей или подписок.

> Указанные версии сторонних ядер относятся к обновлённой рабочей Windows-сборке. Ранее подготовленные исходные ZIP-комплекты могут содержать предыдущие исполняемые файлы; это не отдельные опубликованные бинарные релизы в данном репозитории.

#### 2. SG-Net: все четыре режима подключения

SG-Client интегрирует собственный протокол SG-Net непосредственно в Windows-интерфейс:

| Режим | Назначение |
| :--- | :--- |
| **TLS** | Прямой защищённый транспорт |
| **WSS** | WebSocket Secure поверх TLS |
| **H3 / QUIC** | HTTP/3 поверх UDP |
| **Auto** | Автоматическая попытка H3 → WSS → TLS с переходом на доступный транспорт |

- Отдельный выбор транспорта в профиле SG-Net, без внешнего приложения.
- Импорт ссылок `sgnet://`, профилей и подписок сервера SG-Net.
- Работа SG-Net через общий интерфейс подключения и TUN.
- Для H3 необходим доступ к соответствующему UDP-порту сервера; Auto использует другие режимы, если H3 недоступен.

#### 3. Подписки и управление профилями

- Импорт и обновление профилей из ссылок и подписок; поддержка SG-Net наряду с привычными форматами Xray и других ядер.
- Группы подписок, выбор активного подключения, сортировка и избранное.
- Отдельные профили TLS, WSS, H3 и Auto позволяют сравнивать поведение транспортов на одном сервере.
- Сохранение пользовательских настроек и существующих профилей при обычном обновлении приложения поверх рабочей установки.

#### 4. Маршрутизация, TUN и управление трафиком

- Поддержка **TUN**, системного прокси и локального прокси.
- Управление правилами **Proxy / Direct / Block**, включая категории рекламы и трекеров.
- Работа с GeoIP, GeoSite, DNS и пользовательскими маршрутами.
- Переработана генерация и проверка правил Xray, в том числе при использовании TUN и SOCKS-моста.
- Ускорен старт SG-Net в режиме TUN: убраны лишние временные процессы там, где проверку может выполнить основное подключение.

#### 5. Флаги стран и диагностика

- Обновлена отдельная база GeoIP, используемая для определения стран серверов; данные маршрутизации GeoIP/GeoSite от неё не зависят.
- Доработано сохранение определённой страны при обновлении списка и обработка IPv4/IPv6.
- Для доменов, перенаправленных на локальный адрес через Windows `hosts`, добавлена отдельная попытка определения публичного адреса без изменения самого подключения.
- Тест задержки SG-Net проводится отдельно для TLS, WSS, H3 и Auto; доступны проверки состояния подключения и диагностика.
- Улучшены отображение статусов, компактность интерфейса и работа со списком профилей.

#### 6. Обслуживание и обновление

- В разделе обслуживания доступна проверка и ручное обновление Xray из официальных выпусков.
- Каналы **Stable** и **Prerelease** выбираются отдельно.
- Для сборочного комплекта предусмотрено обновление внешних ядер по запросу, без принудительной повторной загрузки при каждой обычной сборке.
- Сохранены резервное копирование, восстановление и существующие параметры клиента.

Версия 104 развивает единый клиент для Windows: сторонние протоколы и собственный SG-Net работают в общей системе профилей, маршрутизации и диагностики. Доступность отдельных транспортов и результаты GeoIP зависят от сети, DNS и конфигурации сервера.

## SG-Net

**Собственный сетевой протокол · Linux Server AMD64 · Native Go · TLS / WSS / H3 (QUIC)**

SG-Net CLEAN — самостоятельный сервер Security Groups для защищённых подключений. В комплект входят транспортное ядро SG-Net, веб-панель управления, средства для работы с клиентами, конфигурациями и сертификатами. Поддерживается подключение из **SG-Client для Windows** и **SG-Mobile для Android** при использовании совместимых версий приложений.

### SG-Net CLEAN 001A-261101 — Alpha

**Первая тестовая сборка SG-Net CLEAN.** Текущая линия разработки зафиксирована для закрытого тестирования.

| Параметр | Значение |
| :--- | :--- |
| **Выпуск** | `001A-261101` |
| **Дата сборки** | 1 ноября 2026 года |
| **Статус** | **Закрытая Alpha** — для технических тестировщиков, не стабильный релиз |
| **Установщик** | `SG-Net-CLEAN-001A-261101.run` |
| **Платформа** | Linux AMD64 · Debian / Ubuntu |
| **Размер** | 59 347 582 байта (около 56,6 МиБ) |
| **SHA-256** | `bd7cfecd376bed99a597e71c3993cd763ce537a916129a70783bfd6d9cca5b95` |

#### Три транспорта одного SG-Net

| Транспорт | Соединение | Назначение |
| :--- | :--- | :--- |
| **Direct TLS** | TCP/443 · TLS | Прямое подключение по собственному протоколу SG-Net |
| **WSS** | TCP/443 · WebSocket Secure | Подключение SG-Net поверх защищённого WebSocket |
| **H3/QUIC** | UDP/443 · HTTP/3 | Альтернативный транспорт на основе QUIC |

Каждый транспорт можно использовать отдельно. Доступность и скорость зависят от провайдера, сети клиента, конфигурации сервера и ограничений UDP/TCP. Серверная поддержка транспорта не гарантирует работу на любой сети.

#### Панель управления SG-Net CLEAN

- **System:** состояние сервера, загрузка CPU, использование RAM и диска.
- **Clients:** пользователи, устройства, параметры доступа, ссылки и QR-коды профилей и подписок.
- **Connections:** настройки Direct TLS, WSS и H3/QUIC, домены, параметры подключения и служебные состояния.
- **Security / Certificates:** администрирование доступа и TLS-сертификатов для серверной и административной частей.
- **Routing / GeoFiles:** базовая схема выхода через сервер или общий WARP-выход; управление файлами GeoIP/GeoSite.
- **Maintenance:** резервное копирование, восстановление и графическая очистка системного кеша, архивных журналов и выбранных старых `.run` из домашних каталогов.

Панель работает на собственных компонентах **Go**. Установщик содержит предварительно собранные исполняемые файлы; **устанавливать Go или компилировать программу на VPS не требуется**.

#### Что ещё в разработке

**Routing пока не является полноценным движком выборочных правил.** Персональные доменные/IP-правила, категории GeoSite и схема в стиле Check Point запланированы, но не должны восприниматься как уже действующие ограничения трафика. Текущая серверная маршрутизация прежде всего рассчитана на общий Direct либо WARP.

Кроме того, на момент описания ещё не завершена полевая проверка этой сборки на нескольких независимых VPS. В частности, требуют подтверждения одновременная работа TLS/WSS/H3, HTTPS и продление сертификатов, поведение нового шлюза TCP/443, восстановление после отказа и долговременная нагрузка.

#### Для первых тестировщиков

Рекомендуется **отдельный VPS или снимок системы перед установкой**, а не критически важный рабочий сервер. Ориентир для испытаний — **2 vCPU, 1 ГиБ RAM, SSD от 10 ГБ**; это тестовая конфигурация, **не подтверждённый минимальный системный порог**. Потребуются настроенные DNS-записи доменов VPN и панели и доступ к необходимым TCP/UDP-портам.

После получения установщика и проверки его SHA-256:

```bash
bash ~/SG-Net-CLEAN-001A-261101.run --verify
sudo bash ~/SG-Net-CLEAN-001A-261101.run --install
```

Для обновления уже установленной поддерживаемой версии используется `--update-panel`. Режим `--rollback-cleanup` восстанавливает прежнюю схему подключения шлюза очистки на TCP/443; **это не полный откат всей ОС**.

**Распространение:** первая Alpha предназначена для ограниченного круга тестировщиков. Публичная ссылка на RUN будет опубликована после размещения и проверки файла; пока публичной загрузки здесь нет. Репозиторий **sg-products** содержит описания выпусков, а не исходники или установочные файлы.

## English overview

**SG — Security Groups** is a family of networking applications and server management tools.

- **SG-Mobile (Android):** a multi-core VPN client with Shadowsocks, Outline prefix support and SG-Net TLS/WSS/H3. The highlighted release is **084 FIX6**, with refreshed Xray, sing-box, Mihomo and Mieru cores.
- **SG-Client 104 (Windows):** a portable multi-core VPN/proxy client with updated Xray 26.10.29, sing-box 1.14.4, Mihomo 1.19.33, AmneziaWG 3.1, and integrated SG-Net TLS/WSS/H3/Auto, subscriptions, TUN, routing, GeoIP country flags, and diagnostics.
- **SG-Net CLEAN 001A-261101 (closed Alpha):** native Go Linux AMD64 server, web panel, Direct TLS (TCP/443), WSS (TCP/443) and H3/QUIC (UDP/443), client/device and subscription management, certificates, backups and graphical disk cleanup. Selective per-domain routing is not yet active; independent VPS field validation remains in progress. Installer is not publicly hosted.
- **SG-Gateway:** a Linux VPN server management panel.
- **SG-Panel:** a separate Xray-focused Linux control panel with multi-transport management.

**Distribution:** Installers and packages are hosted in Google Cloud Storage. This GitHub repository contains product information only; no source code or distributable binaries.
